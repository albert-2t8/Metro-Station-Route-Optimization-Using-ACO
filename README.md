# Metro-Station-Route-Optimization-Using-ACO
This project uses the Ant Colony Optimization (ACO) algorithm to find the best route between two metro stations.

Additionally, the program randomly selects a station that is temporarily closed and avoids including it in the calculated route. This simulates a real-world situation in which a metro station is unavailable.
